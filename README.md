# radscores-updates

Avis de mise à jour de l'application RadScores.

- `maj.radscores-pack` : paquet signé (Ed25519) qui annonce la dernière version de l'application. L'application refuse tout paquet dont la signature ne correspond pas à sa clé embarquée.
- Adresse à saisir dans l'app (Réglages › Contenu › Adresse des mises à jour) :
  `https://raw.githubusercontent.com/medirumva/radscores-updates/main/maj.radscores-pack`
- Les APK sont dans les [releases](https://github.com/medirumva/radscores-updates/releases) (installation manuelle).

Outil d'aide à la décision, contenu non validé cliniquement.
