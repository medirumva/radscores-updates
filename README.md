# radscores-updates

Fichier d'essai du circuit de mise à jour de l'application RadScores.

- `essai.radscores-pack` : paquet d'essai **sans valeur clinique**, signé (Ed25519). L'application refuse tout paquet dont la signature ne correspond pas à sa clé embarquée.
- Adresse à saisir dans l'app (Réglages › Contenu › Adresse des mises à jour) :
  `https://raw.githubusercontent.com/medirumva/radscores-updates/main/essai.radscores-pack`

Ne pas utiliser pour un usage médical.
